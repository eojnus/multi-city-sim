## 记录约定

每个讨论主题按需要记录：

1. **用户目标**：希望玩家体验到什么。
2. **已确认**：用户明确接受的规则。
3. **讨论中的建议**：供比较的选项和影响，不代表最终决定。
4. **待决定**：仍需选择或补充的关键问题。
5. **与其他系统的关系**：需要时说明对人口、企业、政治、城市、地图和其他机制的影响。
