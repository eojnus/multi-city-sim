# 机制扩展：架构边界与待定事项

状态：任务基线，2026-11-01；依据 `DEVELOPMENT_ROADMAP.md`。这里不是最终游戏平衡方案。

## 需要贯彻的用户决定

- 世界战略地图是虚构世界的一小片平面区域，不是真实地球；暂不改造。城市内部视角单独待定。
- 企业各自独立经营，拥有股权、股票、商品和董事会等相关机制；股东与董事会不是同一个概念。
- 一种股票具有表决权，一种股票仅有分红权。企业作为买方在股票市场买入的股票均有表决权；此规定不能推断个人买入的股票权利。
- 企业融资时可对不同出资方分别约定是否提供投票权；股票权利与具体持股必须可追溯。不要默认可以无偿剥夺已有股东的权利。
- 不同城市的企业可直接贸易；政府可牵头多企业贸易协议，企业有权拒绝参与。每家企业账务、货物、责任独立。
- 每个城市的居民按群体构成多个居民投资实体；普通居民不逐个创建 AI。实体可持有资金、买股和获得分红；有权的持股参与表决。居民投资实体内部明细不在玩家界面展示。
- 通知图标放在最上方 UI 紧下方，点击后才显示可拖动的通知详情窗口。按玩家个人、相关企业和玩家为市长的城市筛选。玩家只是少量持股时，仅通知分红、与其权利有关的投票及重大变化；日常经营去企业页面查看。界面不显示无关系统日志或技术信息，须向玩家提示的错误使用易懂语言。
- 人口信息采用美观动态饼图；悬停扇区有浮动效果，展示类别、人数、比例；各图按各自统计口径计算。

## 分层与文件责任

保持模拟层不依赖 Phaser、Electron 或 DOM，界面只读视图和发出命令。复用现有代码，不以新目录为由重复建立第二套市场或人口系统：

- `src/simulation/population/`：人口状态和群体统计；人口迁移或群体变化时保持人数和资产归属一致。
- `src/simulation/investors/`：居民投资群体、群体资金、持股对应关系和投资决策；身份不等于居民逐人建模。
- `src/simulation/securities/`：股份类别、发行数量、持有人、转让、撮合结算、分红归属；企业买方的市场购买需校验表决权。
- `src/simulation/corporate-governance/`：董事、董事会、会议/议案及持有表决权者的表决记录。避免把持股直接等同企业控制权。
- `src/simulation/companies/`、`finance/`、`production/`、`markets/`、`trade/`：沿用现有企业、财务、生产、商品市场、交易逻辑，按明确契约调用证券和协议模块。
- `src/simulation/agreements/`：政府牵头的跨城市多方协议、企业接受或拒绝、各参与方交易义务及履行记录；参与方账目独立。
- `src/simulation/notifications/`：面向玩家的领域事件、与角色/持股相关的可见通知和已读状态；避免泄露内部模拟日志。诊断保留于开发层，非玩家消息。
- `src/simulation/contracts/`、`core/`：共享稳定类型、集中结算、跨域操作、验证和版本化存档迁移；不在公共类型中塞入某个模块的所有内部实现。
- `src/ui/charts/`：人口饼图和悬停交互；`src/ui/` 负责通知图标与拖动窗口；不要在 UI 内写经济规则。

这些目录是职责预留，允许为现有结构合理调整，但必须同步文档，避免跨模块循环依赖。商品库存与现金各有明确所有者；交易按明确顺序验证并整体提交。

## 一致性约束

股票持有人数量汇总不超过且应匹配对应发行量；股份和投票权随已定义的交易规则转移。交易支付有买卖双方，不允许无中生有；融资资金进入发行企业，二级交易资金进入卖方。任何失败的发行/交易/协议履行不留下部分状态；分红按实际持股分配一次，玩家/居民/企业所得不重复计入。人口投资实体的储蓄及资产属于其居民群体，不能把同一居民既作为投资者又作为新人口重复计算；迁移及群体变动的资产处置要明示并守恒。

用户未决定的具体股权定价、个人市场股票权利、表决票制、董事会席位、企业控制权、居民群体阈值与风险偏好、城市市长产生方式、协议生效/退出/违约规则、少量持股阈值、通知重要程度等，均不是既定事实。为可运行原型设置的假设需集中配置、可替换并在文档标“暂定”；不得将融资时已有出资方权利悄悄改变。

## 先修复的已知缺陷

1. 已存在但读取失败的自动存档可能被覆盖：区分不存在与读取出错并保护文件。
2. 经营计划读取上月销量前先被重置；应区分上期和本期，核对出口销量口径。
3. 零员工仍能生产；按实际员工、生产率和可用产能/投入实施合理约束并验证。
4. 当前支持率提升使迁移吸引力降低；核对其含义后修复方向。
5. 无供应但采购前借款：究竟是独立经营备资还是随成交融资尚待决策。不要把该选择伪装为已获批准；给出可追溯的暂定行为及影响。
