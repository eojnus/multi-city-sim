# Git 与协作

main 为已验收基线，develop 为集成分支，每项开发使用单独的 feature 分支和 worktree。此项目初始化后先提交项目任务资料作为基线，再从 develop 创建 feature/first-playable 的独立 worktree；不要让多个 Agent 在同一个工作区改文件。

提交前运行必要检查，说明变更、运行方式和未完成事项。架构负责人审查结果和公共契约，再合并到 develop；里程碑验收后再合并到 main 并标记版本。不推送远程、不重写共享历史；未经授权不执行破坏性操作。资源包的再分发权限必须在提交和发布前核验，原始下载包不进 Git。
