# 外部 Agent 任务书：可运行初版

## 目标与工作方式

在 `feature/first-playable` 的独立 Git worktree 中交付可运行、可操作、可存档的桌面原型。先完整阅读 `docs/PROJECT_PLAN_v0.2.md`、`docs/architecture/ARCHITECTURE.md` 和资源清单。总计划中候选公式和未确定数值均为可替换的演示规则，不得写成已获批准的最终设计。先建立骨架，再逐项实现和验收。保留每项限制与未完成内容。不要推送远程、重写历史或随意修改其他 worktree。

## 初版交付范围

1. TypeScript + Phaser + Electron 桌面应用；安装、启动、构建及打包步骤清晰，窗口可正常退出。Electron 关闭 nodeIntegration、启用 contextIsolation，通过最小 preload 接口访问存档。
2. 区域地图展示三座城市、区域范围和交通/贸易连接；点击城市可进入城市地图并返回。至少一座城市拥有道路、住宅、商业、办公、工业和公共设施或公园，街区可点击并查看信息。城市概况以及人口、经济、产业图层可切换，数据明确区分演示和模拟结果。
3. 有统一时间、暂停/推进、初版可见的月度结算和可复现随机种子。模拟独立于 Phaser/Electron。支持保存、读取与重新启动后的恢复，存档带版本，出错有提示。
4. 三座城市有权威人口和人口状态、企业岗位与工资、少量商品、居民消费与企业采购、生产配方及库存、成交、价格、游戏简化 GDP；可以推进多期并观察变化。用少量示例数据实现最小闭环，清楚标注假设，不要求成熟平衡。至少有一个跨城市货物流动示例。收入、支出与库存来源要可追溯，不得凭空复制商品或员工。
5. 玩家有初始账户，至少能进行一项实际影响模拟的投资或企业操作；政治、科技、房地产提供可查看的初始状态和明确标识的后续入口，禁止用不可点击按钮冒充完整系统。初版无需完整国家、军事、外交或复杂物流。
6. 内建美术资源目录和来源、许可、作者、文件清单；按 `assets/manifests/sources.md` 获取并核验 Rasak Modern 和 Kenney UI Pack，生成预览及至少一个实际街区。备用 Kenney 资源保持独立视觉体系。不得提交无权再分发的原包或素材。如果下载需登录、付费、人工选择或限制网络，记录实际阻塞和手动获取步骤；不可绕过限制或声称已完成。资源不可用时可用明确标注的临时占位继续验证，不得把它当最终资源交付。

## 工程与实现约束

- 在 `src/app`、`src/platform`、`src/presentation`、`src/ui`、`src/simulation/core`、`src/simulation/contracts`、各领域目录与 `src/data` 实现；按实际需要增加文件，不造大量空类。资源由集中清单加载，不把资源路径散落在业务代码。
- 状态只能由所属模块或明确的事务协调器修改；UI 不直接改写世界状态。人口迁移、雇佣、库存转移与交易需要全部成功或全部失败。每期检查人口、就业、库存与成交约束。
- 模拟流程、确定性、存档、示例数据和假设写清楚；固定种子、相同输入得到相同结果。GDP 口径记录投入和产出，避免将营业额当 GDP。模拟数值为演示参数，集中配置。
- 完成必要的自动化检查：守恒与交易失败回滚、固定种子重现、存档往返；执行类型检查、构建以及最小启动验证。不能实际执行的检查必须说明原因和证据。
- 更新 README，提供 Windows 下可复制的安装、启动、构建、打包及验证步骤；记录依赖版本、许可证、美术使用范围和已知限制。
