## 2. 验收问题修复

### 2.1 企业融资可获得仅分红股份（市场买入限制不再外溢）

修复前：`securities.createFinancingOffer`、`acceptFinancingOffer`、持股不变量与存档校验都把“企业不能持有仅分红股份”当成通用规则，导致企业出资方无法获得仅分红股份，合法存档也会被判为损坏。

修复后：

- **市场买入**：`placeOrder` 只在 `side === 'buy'` 且买方为企业时要求股份类别为 `voting`；撮合与存档校验同步遵守。
- **企业融资**：`createFinancingOffer` / `acceptFinancingOffer` 允许向企业出资方发行 `nonVoting`；持股与要约校验不再拒绝。
- **出售**：企业可以卖出其合法持有的仅分红股份（限制只作用于买单）。
- **权利可追溯**：每份 `ShareHolding` 记录 `shareClassId`、持有人类型/ID、股数、取得方式；仅分红股份不产生投票权，但按股获得股息。
- 新增测试：
  - 向两家企业分别融资，一家获得有投票权、另一家获得仅分红股份；接受后资金进入发行企业、持股类别正确、仅分红方投票权为 0、可获股息；
  - 同一企业在二级市场买入仅分红股份被拒绝；
  - 企业出售合法持有的仅分红股份可以成交；
  - 含企业仅分红股份的世界可存档并读回。

### 2.2 居民股息不再重复计入

修复前：`distributeDividend` 先把整笔股息计入实体现金，`investorDistributionByCity` 又按 70% 计算返还额加入居民收入，但未从实体现金扣除。验收场景中：实体现金 +896，同时 627.20 计入居民收入，资金被重复使用。

修复后：股息在分配时立即拆分——

```text
投资实体实收股息 = 实体现金留存 + 返还居民收入
返还部分 = round2(实收 × dividendDistributionRate)   // 默认 70%
留存部分 = 实收 − 返还部分                              // 精确补差
```

返还额一次性从实体现金扣除并随 `FinanceResult.investorDistributionByCity` 进入居民可支配收入；`collectInvestableFunds` 再从可支配收入中划出 6% 储蓄。玩家、企业、居民实体所得互斥，合计等于企业派发额。

- 复现场景测试（新增）：896 → 留存 268.80、返还 627.20，实体现金只增加 268.80，`268.80 + 627.20 = 896`。
- 完整结算测试：核对居民收入公式只包含返还额一次、储蓄划转扣除、实体现金 = 留存 + 储蓄分摊。
- 多期测试：24 个月后实体现金非负、股票交易与股息可追溯、不变量通过。

### 2.3 场景切换后窗口缩放报错

桌面验收在离开城市场景后调整窗口大小会触发 `Cannot read properties of undefined (reading 'setViewport')`：`CityScene` 注册了匿名 resize 监听且未在 `SHUTDOWN` 时移除，场景销毁后仍访问 `cameras.main`。已改为具名处理器、在 `SHUTDOWN` 时注销，并对相机存在性做防御检查；区域场景的 `fitCamera` 同步加保护。修复后机制验收脚本无 console error。

## 3. 完成的功能与操作

### 企业、股权、董事会

- 每家企业独立现金、债务、库存与两类股份（有投票权 / 仅分红）。
- 企业详情新增：股权结构（股东、两类持股、占比）、董事会与经营者、议案与表决、二级交易与融资方案。
- 表决：股息政策与经营者任命议案按股加权；通过后真实改变 `dividendPayoutRatio` 或 `control.operator`。玩家有投票权时可在企业页面投票，未投票视为弃权。
- 股东、董事与经营控制权分离：默认经营者为职业经理人，持股只产生投票权与席位。

### 股票市场与居民投资

- 一级融资：`注资` 资金进入企业并增发有投票权股份；企业融资会向玩家发出可接受/拒绝的要约，逐出资方记录股份类别（70% 以上场景中居民实体、企业、玩家可获得不同权利）。
- 二级市场：限价订单簿；买入/卖出按钮（100 / 1000 股）；资金只在买卖双方之间转移；不冻结资金/股份；同一持有人不会与自己撮合。
- 每城 3 个居民投资实体：资金、持股、股息与自动投资；不展示内部明细。

### 跨城协议

- 市政府（演示入口）可组织与伙伴城市的多企业买卖协议；参与企业逐个接受/拒绝。
- 条目逐项原子履约；失败只标记条目并说明原因，不留下部分扣款或货物转移。
- 界面显示参与方决策、商品、数量、单价、已交付与状态。

### 通知与人口图

- HUD 正下方仅显示通知图标与未读数；点击后打开可拖动、可关闭的详情窗口（Esc、点击外部关闭）。
- 通知按身份过滤：个人、持股企业、市长（演示）城市；无投票权不会收到表决通知；低于 5% 持股只保留分红、可参与表决和重大变化。
- 城市概况动态环形图展示就业/失业/非劳动力，悬停或键盘聚焦扇区浮动并显示类别、人数、比例；口径说明避免把劳动力与总人口相加。
- 日志隐藏系统结算条目与技术校验信息；存档错误以易懂语言显示在通知窗口顶部。

## 6. 暂定规则与待决事项

- 个人在二级市场买入是否带投票权：当前演示允许并按个人选择记录，尚未由用户决定。
- 两类股份同价、按股同额分红；股息默认派发比例 0.6，可由议案改为 1.0。
- 董事会 5 席，按投票权比例每月重算；一票一股；经营者默认职业经理人，须议案任命。
- 居民投资实体每城 3 个，储蓄率 6%，股息返还 70%，自动投资规则与跨城买股为演示参数。
- 政府协议自动配对、接受阈值、3 个月期限、无违约罚则；由“市政府（演示）”入口发起，不代表市长选举已实现。
- 少量持股阈值 5%、重大变化标准、通知保留 120 条为演示配置。
- 企业无供应时是否允许独立备资借款仍未决定；当前为“成交后按实际支出融资”。
- 股票定价只有账面价；投资者资金缺少债券/存款出口。
